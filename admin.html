Админ-панель

Товары витрины хранятся в файле products.json в репозитории GitHub. Чтобы сохранять изменения, войдите с помощью токена доступа GitHub.

Как получить токен (2 минуты)
  1. Откройте GitHub → Fine-grained tokens → Generate new token.
  2. Token name: «Nika admin», Expiration: 90 дней.
  3. Repository access → Only select repositories → nika-business.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Нажмите Generate token, скопируйте токен и вставьте в поле выше.

Токен хранится только в этом браузере и даёт доступ только к одному репозиторию. Никому его не пересылайте.
