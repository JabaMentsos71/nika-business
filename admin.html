Админ-панель

Товары, баннеры и оформление магазина хранятся в репозитории GitHub. Чтобы сохранять изменения, войдите с помощью токена доступа GitHub.

Как получить токен (2 минуты)
  1. Откройте GitHub → Fine-grained tokens → Generate new token.
  2. Token name: любое, например «Админка магазина».
  3. Repository access → Only select repositories → выберите репозиторий магазина.
  4. Permissions → Add permissions → Contents → Read and write.
  5. Нажмите Generate token, скопируйте токен кнопкой копирования и вставьте в поле выше.

Токен — это пароль: он хранится только в этом браузере и даёт доступ только к выбранному репозиторию. Никому его не отправляйте.

Резервная копия и новый магазин

Сохраните все товары, баннеры и настройки в один файл, чтобы восстановить их позже или перенести в новый магазин.

Как сделать ещё один магазин на этом шаблоне
  1. На GitHub откройте этот репозиторий → Settings → включите Template repository (один раз).
  2. Нажмите Use this template → Create a new repository, задайте имя, например flower-shop.
  3. В новом репозитории: Settings → Pages → Branch main / root → Save.
  4. Создайте токен для нового репозитория и откройте https://ВАШ-ЛОГИН.github.io/flower-shop/admin.html.
  5. На вкладке «Оформление» задайте название, логотип и цвета, на «Товары» — свои товары, и нажмите «Опубликовать».

Каждый магазин живёт в своём репозитории и не влияет на остальные.
